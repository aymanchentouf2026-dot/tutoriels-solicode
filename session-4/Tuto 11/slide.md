# Veille technologique : Modularité et fonctions en PHP

## 1. Technologie
- **Nom :** PHP
- **Logo :** PHP Official Logo

## 2. Définition
La modularité en PHP consiste à diviser le code en plusieurs fichiers et fonctions réutilisables pour organiser le projet et éviter la répétition du code.

## 3. Problème technique résolu
La modularité permet d'éviter la répétition du même code dans plusieurs pages, de faciliter les modifications et de rendre le projet plus facile à maintenir.

## 4. Trois mots-clés
- **require_once :** inclure un fichier une seule fois.
- **Fonctions :** réutiliser un même bloc de code.
- **DRY :** Don't Repeat Yourself (ne pas répéter le code).
